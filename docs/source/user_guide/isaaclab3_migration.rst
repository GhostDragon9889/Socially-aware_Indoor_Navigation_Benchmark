IsaacLab 3.0-EA / Isaac Sim 6.1
==============================

Use the fixed SDK profile in ``env/isaaclab3_ea_sim61``. Bind an existing SDK with ``scripts/bootstrap_reproduction.py configure`` or install a new SDK with its ``install`` action, which uses uv. Run project entry points through ``scripts/run_external_python.py``.

SDK providers, asset hashes, source ownership and physical quality are checked separately. The old Sim 6.0 installation profile and native overlay are retired. See ``docs/guides/installation.en.md`` and ``docs/validation.md``.
