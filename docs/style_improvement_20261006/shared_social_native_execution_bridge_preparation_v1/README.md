本批提供固定S3候选、显式seed原生SDK及raw-CPU退出的发布接口。
接口要求实际工具终态的chunk、严格整数退出码和原命令一致；失败退出保留原值。
成功准入还要求外部根观察者已经确认S3 owner cell581完整结束，
因此训练退出凭据本身不会提前释放后续评估所用GPU。
