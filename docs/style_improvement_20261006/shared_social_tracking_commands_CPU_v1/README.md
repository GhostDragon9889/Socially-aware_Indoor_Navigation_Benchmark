## 严格时间与坐标定义

第0帧只记录初始重置；第1帧的动作仍使用第0帧的身体和参考相位。
随后每控制步的观测使用前一POST状态，查询+0.5..5s的10点，物理时钟增加4子步；
随后POST状态才与当前参考帧比较。命令只能在片段尾部保持，评价分母不延长也不裁剪。

原始前缀按已测PRE根部XY与其实际projected-X heading重算：
float64相减、旋转，末尾转float32。数值界限为half float32 spacing加
32 float64 eps乘原始差值的L1幅度；没有使用统一米级容差来掩盖错帧。
朝向wrapped比较保留float32计算差；奇异fallback仅允许真实PRE跌倒、同episode已有定义朝向。
原始全身世界坐标误差数组和失败锁存先逐值验证，没有重定义跟踪成功。
