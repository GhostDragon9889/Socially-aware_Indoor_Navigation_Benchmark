# PACER 奖励比例：预注册单变量实验

## 改动与来源

沿用上一轮的公共状态判别器先验、AMP历史统计、动作输入、地形统计保护和固定半AMASS／半procedural课程，仅将AMP外部权重从2降至0.5；配置的两处同义声明同步。内部尺度保持2，因此基础softplus奖励系数从4变为1，任务权重仍为0.5。

这一比例与[公开PACER作者配置](https://github.com/nv-tlabs/pacer/blob/baeb6241f03fc9d78370a64e3c2dcef9d830d97f/pacer/data/cfg/train/rlg/amp_humanoid_smpl_sept_task.yaml#L93)一致。[NavIsaacLab论文](https://arxiv.org/html/2606.26265v1#S4.SS2)未说明内部奖励缩放，不能据此判定其实现错误或声称新配置已等同作者私有配置。[完整资料核对](../paper_fidelity_research_v1/README.md)区分论文、公开代码和本地工程假设。

代码同时修正独立的恢复准入问题：旧入口会在新奖励profile下静默沿用checkpoint中的旧奖励参数。修正版仅在训练恢复时比较五项奖励合同并拒绝不匹配；fresh训练和纯评估不执行该检查。此修复不改变本轮fresh训练的数学或构造随机数。

## 固定训练条件

- 2,848个真实AMASS片段，原manifest、训练bank及22验证／34测试划分不变。未读取34条测试输出。
- 256环境×32步×2,000更新，16,384,000转换；每课程分支8,192,000转换。
- seed7、PPO、学习率、10帧历史、2019维判别器、57有效动作、公共冷初始化、replay、mirror50和有符号物理子步功率不变。
- `expert_sampling=null`，本轮不叠加分层采样或新增姿态条件。分层采样的ESS和来源集中度取舍见[独立研究](../style_sampling_research_v1/README.md)。
- 新隔离目录保留旧934文件来源，仅纳入两个已审查的恢复检查delta和一个新profile；不得修改历史副本或转换旧checkpoint。
- fresh pilot4真实退出并通过状态检查后，另起fresh2000；完整训练没有`--resume`。快照独立保存500／1000／2000轮，保留全部训练失败。

以上是运行前方案，准备记录与真实执行记录分别保存；没有结果时不写效果通过。

## 固定评估顺序

1. 终态权重真实退出、封存且通过完整checkpoint、优化器、replay、RMS、课程、RNG和来源核验。
2. 固定validation22全部11,982计量帧，阈值0.5m；保留失败、逐关节位置／旋转、腕／肘误差及原90D分桶。复用旧跟踪参考和计量数学。
3. 原四人fixture完整6,000控制步／200s，保持场景、Diffusion5000、规划参数、seed7、接触阈值>1N、原始状态和足部计量。记录路线、停滞、接触、跌倒、COM与支撑。
4. 沿用c274固定AMASS参考、b25固定45D中心和原核参数，不重新fit。保留全部七个90D速度桶与未知值；主要均值和共有桶补充比较同时报告，不通过改变支持总体宣称改善。
5. 若fixture完整且零跌倒／零接触，再做同V5 Warehouse四人原生200s；风格分数较差也保留，不以此过滤已经得到的结果。四人完整零跌倒／零接触后，再做同V5 15人200s。
6. 新Office地图预检及真实重力短探针单独登记；通过后才扩展物理评估。四USD×两密度是八个本地上下文，不冒称作者八个不同场景。

## 比较与选型

主要训练机制对照是同预算上一轮state-prior2000。部署对照还包括当前默认state-only1000，明确预算和历史源码不同。所有结果必须同时报告路线、物理稳定性、上肢误差、共有速度桶风格和固定姿态覆盖。

不自动替换默认模型。候选需要在原生场景保持零跌倒／接触，同时改善上轮路线进展，并避免姿态覆盖和上肢误差的明显退化。局部通过不代表达到论文；论文的原始2848 IDs、完整八场景清单和指标细节仍未公开匹配，不能直接用本地MMD数值排名。

当前状态以新准备目录、真实启动记录和后续完整报告为准，旧实验报告保持原字节。
