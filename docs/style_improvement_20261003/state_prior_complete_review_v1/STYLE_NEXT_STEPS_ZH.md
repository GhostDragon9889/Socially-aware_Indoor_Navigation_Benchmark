# 本轮之后的动作风格优化依据

这是后续设计记录；本轮新增方案没有进一步启动训练或被替换进默认模型。

## 已定位的具体问题

- 新公共先验2000在完整22条中17条成功。相对匹配的地形保护2000，位置改善、旋转及左右腕父关节误差退化；[完整24关节证据](joint_error_comparison.json)含全部帧。
- 四人fixture停滞降至0.1333人秒，持续行走明显改善。90D原汇总支持3桶、基线5桶；共同3桶为0.06811695对0.04098256，新模型逐桶均更差。
- 固定45D中心下K50／100覆盖0.58／0.52，基线0.86／0.72；没有通过增加训练轮数证明多样性改善。
- 原生Warehouse四人／15人实际200秒均零跌倒和接触；同场景共有速度桶90D与固定45D姿态距离改善，但到达从57／211降至44／160，15人K50覆盖从0.76降至0.70。这些取舍与fixture结果同时保留，不能以一个场景替代另一个。

## 方法资料与适用范围

[AMP原论文](https://arxiv.org/abs/2104.02180)使用来自动作数据的判别器奖励学习动作分布，并通过PD目标控制物理角色。整体分布学习不能保证逐条参考动作跟踪；当前22条诊断与自由导航风格需要分别报告。

[ASE作者项目与代码](https://nv-tlabs.github.io/ASE/)学习可复用技能嵌入，提供进一步控制不同技能的结构。项目本地已有ASE实现，但把它接到当前导航控制器需要新条件输入、相应训练与独立配置；这是方法扩展，不能冒称原NavIsaacLab Diffusion＋AMP的相同算法。

[ADD原论文](https://arxiv.org/html/2505.04961v1)讨论整体分布匹配可能丢失动作模式，并用参考姿态差分实现精确跟踪。该方案需要参考姿态输入；当前部署只有扩散轨迹、物理自身状态和地形，因此整合需要额外姿态生成接口及单独验收。

## 后续试验的约束

1. 先保留当前2848真实AMASS、训练／验证／测试来源和划分。验证22全部失败帧保留，34条测试输出继续封存；文件名代理标签不能冒充作者标注。
2. 单次训练只改变一个可解释机制。逐速度桶、足部支撑、上肢局部旋转与固定45D覆盖必须同时报告；下一次主要同速比较需预先固定公共速度支持范围，不能依缺失桶改善汇总。
3. 完整恢复继续保存模型、两个优化器、判别器replay、归一化统计、课程与RNG；新增风格输入或奖励必须写入checkpoint合同和显式可选配置。
4. 真实native4／15的原始接触、路线、风格和媒体比较已经完成。下一轮需同时改善路线进展与动作覆盖，并扩展到其他原生场景。固定seed与公开参数不意味着旧1950D和新2019D模型的部署初始化会消费相同随机数；不能据此宣称规划噪声逐位配对或单一因果效应。

当前默认模型仍为原state-only step1000。本地指标与作者未公开的完整八场景、2848动作IDs及TableIII参数不同，尚不能证明达到或超过论文效果。
