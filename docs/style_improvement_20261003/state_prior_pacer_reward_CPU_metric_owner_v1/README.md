# Actual CPU metric process owner

This wrapper executes the five unchanged commands from the frozen new935 metric catalog. It adds actual process closure records, sealed output hashes and the exact closed GPU owner record. It changes no measurement code, reference population, basis, numeric rule or command argument.

Preparation validates only frozen sources. Actual execution requires root's readonly closed evaluation receipt and an unused metric output. A child failure or owner failure is retained; it is never retried into the same output. Navigation raw receipts use `pacer_reward.actual_CPU_metric_launch.v1` and bind `artifacts.raw_report` and `artifacts.source_sidecar` for the registered native physical admission.

Run order is tracking90, tracking_decomposition, navigation_raw, navigation90, navigation45. Root must first notify the corresponding real GPU evaluation has closed and been sealed. All CPU children disable CUDA. A successful metric process is not a quality or promotion claim.
