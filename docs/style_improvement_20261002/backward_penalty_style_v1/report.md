# 方向奖励消融：完整 22 条跟踪与风格对照

2026-10-02，CPU 事后分析；本次没有启动 Kit/CUDA，没有修改模型、训练代码、数据、配置或冻结评估器。使用已经完成的真实 PhysX 轨迹。

**结论：反向惩罚明显改善这轮低层跟踪，但还没有达到论文效果或解决全部动作风格问题。** 新模型成功 11/22、跌倒 0/22，原 v7 正号模型成功 5/22、跌倒 2/22。速度分布、脚部代理及部分腕部姿态没有全面改善。

每组完整评估相同 22 条动作、11,982 个实际 post-step 帧，初始 reset 帧不参与误差；跌倒帧保留。成功规则是整条动作每一个测量帧的 24 个世界坐标身体原点平均距离均不超过 0.5 m，不能用整条平均误差代替成功率。

MMD² 是本项目明确实现的速度分层 90 维局部位置/速度 Gaussian biased MMD²，sigma=1，最多平衡抽取 256 样本/速度桶、至少 30 样本，五个支持桶等权平均。它不等于作者未公开的精确 MMD 参数或验收门槛。新模型 upright 保留 100%，因此两列相等。正号模型 upright 保留 95.9448%；去掉非直立帧后的 0.045422 仍略优于新模型 0.046821，主指标大幅改善包含了清除跌倒帧的贡献。

论文目标在原捕获协议中记录为位置 0.218 m、旋转 0.343 rad、成功率 0.646；本次依然分别是 0.300708 m、0.861454 rad、0.5。作者精确误差协议未知，这些数值只能作为目标参考，不能作为已复现证明。本次是独立环境内、真实 future-XY oracle 指令的低层控制评估，尚不是 learned Diffusion 避障或作者八场景实验。

## 方向项是否真是单个配置变化

实际两份训练 `result.json` 的 `TrainingConfig` 仅 `direction_mode` 从 `paper_equation` 改为 `backwards_penalty`；CLI 仅配置路径和输出路径改变。初始化、公开 PACER 迁移权重、数据源、curriculum、physics、power measurement、执行设置、源代码 provenance、seed/numerics 全部相同。两轮均为 1,000 次更新、8,192,000 transitions、32,000 control steps。

另逐个读取 22 对 NPZ 验证：全部 reference 数组、时间/帧号、目标 XY、clip-tail hold、episode/reset 标记逐元素相同；初始 root/DOF/body 状态、速度及 AMP history 也逐元素相同。训练没有 PhysX bitwise 保证；策略改变后的真实 rollouts、跌倒/reset 和随机数消费会自然分岔，不能把相同 seed 表述成全过程相同。

| 第 1,000 次更新记录 | printed 正号 | backward_penalty |
| --- | ---: | ---: |
| backward fraction | 56.6284% | **2.2339%** |
| 机体前向速度平均 m/s | -0.177596 | **0.885803** |
| 方向奖励平均 | +0.232854 | -0.001680 |
| 训练累计 fall resets | 414 | 313 |

这是对论文 printed 正号式的明确语义修正消融：正号项给负前向速度正奖励，惩罚模式反转该项。不能称惩罚模式仍精确复现 printed 等式。[论文 IV-B](https://arxiv.org/html/2606.26265v1#S4.SS2)

完整动作中，20/22 的平均位置误差改善，18/22 的平均旋转误差改善；新增七条成功，失去一条成功：`SFU/0005/0005_BackwardsWalk001_poses.motion`。反向惩罚对合法倒走参考存在明确取舍，后续应区分“违背指令的倒走”和“指令需要倒走”。本次没有混入尚未集成的分层专家采样器。

## 脚部代理的边界

这些历史捕获没有 ground-support 力、真正接触点速度或真实 body COM；相关字段保持 null。以下仅为 toe **身体原点**近地高度和垂直速度阈值的代理：

| 模型 | eligible foot intervals | 近地 toe 原点速度均值 m/s | 超过 0.1 m/s 比例 |
| --- | ---: | ---: | ---: |
| 正号 child1000 | 15,670 | 0.682437 | 32.2527% |
| backward_penalty1000 | 18,692 | 0.725802 | 35.1220% |
| 固定 AMASS 参考 | 16,922 | 0.575501 | 43.3400% |

新模型代理没有改善，eligible 人群也不同。参考本身存在较高代理值，进一步说明此代理不能直接等同于实际接触滑脚，也不能据阈值比例对控制器作真实摩擦验收。真实 ground-support 捕获应另做新评估，不能事后为这些 NPZ 补造接触数据。
