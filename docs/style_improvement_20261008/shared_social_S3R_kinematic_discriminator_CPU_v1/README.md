# S3-R 静止姿势／刚体平移：实际 CPU 判别器对照

## 本批做了什么

上一批[时间历史诊断](../shared_social_S3R_temporal_discriminator_CPU_v1/README.md)发现重复当前帧可提高奖励，
但这种扰动保留原速度，可能违反运动学一致性。
本批增加两个对照：固定当前姿势并将全部观测速度置零；
固定当前姿势并保留根部线速度，将角速度及关节速度置零。
后者对应整个身体以固定速度平移，不能据此认定地面滑步在动力学上可行。

使用已完成 S3-R 第 12,500 次更新权重、原 10 帧／2,019 维判别器、共享 195 维逐帧 RMS 与原 AMP 奖励函数。
8,192 个策略窗口、4,096 个实际 AMASS 专家窗口全部保留，四种条件共评分 49,152 对历史／动作。
每种条件保持原实际施加动作／专家动作代理；没有将对照输入加入专家训练数据。

实际 CPU 执行退出 0，未初始化 CUDA 或启动 SDK。
原历史与重复当前帧的逐窗口 logits／奖励和上一批保存数组完全相同；
全部新保存分数的统计量通过独立 CPU 逐值核对。

## 实际结果

| 条件 | 策略窗口平均 AMP 奖励 | AMASS 专家平均 AMP 奖励 |
| --- | ---: | ---: |
| 原历史 | 0.409293 | 3.613396 |
| 重复当前帧，速度保持 | 2.204078 | 3.817751 |
| 静止姿势，速度置零 | 3.074379 | 3.958297 |
| 固定姿势，刚体平移 | 2.990079 | 3.927609 |

策略窗口中静止／平移对照的奖励分别在 99.9634%／99.9146% 的行上提高；
真实专家窗口对应比例为 95.0439%／94.0186%。
本批进一步说明该冻结判别器在这些输入上偏好低关节运动的对照，
而非仅由“重复帧却不清零速度”的输入矛盾造成现象。

**这些是运动学对照，不是真实物理站立或滑步实验。**
姿势可能包含跌倒状态，未验证接触、支撑或力矩平衡；全部失败窗口仍保留。
评分使用更新后权重与该次更新前捕获输入，不重现原训练奖励 trace，
也不能证明该偏好造成路线停滞或代表独立动作风格质量。

固定 AMASS 数据也包含合理的慢速／停顿动作，不能仅据本批将全部静止动作标为负样本。
当前 episode2000 配方与来源保持；需先完成其独立跟踪、风格与路线／物理评价，
再决定是否开展单独登记的奖励平衡、命令条件或时间一致性候选。

## 独立身体状态编码核对

另读取全部 8,192 个实际 POST 身体快照，逐个生成十帧静止／平移身体状态，
调用[原观测编码](../../../CrowdSim/humanoid/amp/observations.py)验证特征块处理。
这批 POST 状态仅用于编码核对；判别器评分仍使用原 PRE 窗口，未混用相位。

静止对照与特征块处理最大差为 0。
平移最大差为 3.486872e-6，全部来自 float32 世界位置平移后相减的关键身体位置块；
其余 183 维最大差为 0。
CPU 重编码与原 GPU POST 当前帧的最大差为 1.907349e-6，未改写原捕获或评价指标。

速度块来自[PACER 本地原始编码](../../../third_party/pacer/pacer/env/tasks/humanoid_amp.py)：
6D 根部旋转、3D 线速度、3D 角速度、114D 关节旋转、57D 关节速度、12D 关键身体位置。
[AMP 原论文](https://xbpeng.github.io/projects/AMP/AMP_2021.pdf)使用状态转换学习风格，
本批以该时间观测机制为依据，不补造 NavIsaacLab 未公开的训练细节。
